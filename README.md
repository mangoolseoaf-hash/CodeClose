## ✨ ¿Qué es CodeClose?

**CodeClose** toma tu proyecto Python (en un `.zip`) y lo convierte en un **ejecutable `.exe` cerrado**, listo para distribuir, sin que nadie pueda abrir ni leer tu código fuente con un simple clic derecho.

🧠 Compila a C nativo con **Nuitka**
🛡️ Ofusca y protege tu lógica
📦 Empaqueta todo en un único archivo
🖥️ Interfaz moderna hecha con Electron — arrastra, suelta, listo

---

## 🖼️ Vista previa

> Arrastra tu `.zip` → elige las opciones → pulsa **Cerrar código** → recibe tu `.exe` 🎉

```
📂 mi_proyecto.zip   ──▶   🔒 CodeClose   ──▶   🚀 mi_proyecto.exe
```

## 🚀 Instalación y uso

### ✅ Requisitos previos (una sola vez)

| Herramienta | Versión mínima | Enlace |
|---|---|---|
| 🟢 Node.js | 18+ | [nodejs.org](https://nodejs.org) |
| 🐍 Python | 3.8+ | [python.org](https://python.org) *(marca "Add to PATH" al instalar)* |

### ▶️ Arrancar la app

No necesitas instalar nada manualmente. Solo:

1. Descarga o clona este repositorio
2. **Doble clic en `start.bat`** 🖱️
3. La primera vez instalará automáticamente lo necesario (puede tardar un par de minutos) ⏳
4. ¡CodeClose se abrirá listo para usar! 🎊

```bash
git clone https://github.com/xL1F3Software/CodeClose.git
cd CodeClose
start.bat
```

## 🧭 Cómo cerrar tu primer proyecto

1. 📥 Arrastra tu proyecto `.zip` a la ventana (o haz clic para seleccionarlo)
2. ⚙️ Elige el punto de entrada, el nombre del `.exe` y las opciones:
   - 📦 **Un solo archivo** — todo empaquetado en un único `.exe`
   - 🕶️ **Ofuscar y proteger** — dificulta la ingeniería inversa
   - 🙈 **Ocultar consola** — ideal para apps con interfaz gráfica
3. 🔒 Pulsa **"Cerrar código"**
4. ☕ Espera mientras CodeClose descomprime, analiza, compila, protege y empaqueta
5. ✅ ¡Descarga o abre la carpeta con tu ejecutable cerrado!
